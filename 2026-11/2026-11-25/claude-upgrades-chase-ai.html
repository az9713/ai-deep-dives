1. Artifacts as desktop apps

An eligible Claude artifact, such as an interactive tracker, can open in its own Mac or Windows window with its own app icon. In Claude Desktop, open the artifact and choose Share → Install as app. It can still call Claude and use your connected tools. Claude calls count toward your plan, and the app requires a signed-in, online Claude account.

Availability. Beta on all plans, with Enterprise opt-in and some organization restrictions. Claude Docs, Slides, and Sheets cannot be installed this way.

2. MCP upgrades

The Model Context Protocol connects Claude to external tools and data. Chase calls this release “MCP 2.0.” Anthropic’s announcement describes four capabilities for compatible connectors.

  • Skills over MCP. The server can publish workflow instructions alongside its tools, so Claude learns how to use them together. Public beta.
  • Tasks. The server can keep a long-running export or analysis going in the background while Claude continues the conversation. Generally available.
  • Elicitation. A server can pause and ask for missing input or explicit confirmation. Chase illustrates this with a hypothetical repository deletion that asks you to type its exact name. Generally available.
  • File uploads. A compatible connector can receive a file directly, keeping the raw file outside the model’s context window. Anthropic announced a gradual rollout.

3. Code Mode

In the experimental terminal mode, Claude writes JavaScript to coordinate several tool calls in one step. The code can group independent calls in parallel, run dependent calls in order, and decide which results to send back into the model’s context. The video’s example finds a retry-policy file, edits it, runs a test, and returns the path and test result.

Setup in the video. Use native Claude Code v2.1.323 or later for the baseline setup, set CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 in your shell or the env block of ~/.claude/settings.json, and start a new interactive terminal session. Some configurations require newer versions.

4. /ship

From a local Claude Code session, /ship can commit your changes, push the branch, and open a GitHub pull request (PR) under your account. Claude reviews the change and can push fixes for failed checks, review feedback, and merge conflicts during a watch of up to seven days. You handle the merge.

Existing PR. Use /steward to start watching an open PR and skip the initial review. A local watch depends on the session and computer staying active. Anthropic’s current docs say the watch does not start on native Windows.

5. Whiteboards

Whiteboards give you, your teammates, and Claude a shared canvas for brainstorming and presenting. You can draw and arrange material yourself, leave comments for people or Claude, and ask Claude to create or update parts of the board. Chase’s example turns a prompt into an illustrated product-launch timeline that the team can keep editing.

Availability. Beta on paid plans.

6. Sheets

Claude and collaborators can edit the same spreadsheet. Ask Claude to import or organize CSV data, fill cells, create formulas, or revise a table directly. The video demonstrates a plain-English instruction to sum a column and reports support for more than 250 functions.

Scope. Chase recommends Sheets for ordinary spreadsheet work. It has no Excel VBA or macros. Beta on paid plans.

7. Claude Data

Claude Dashboards graduated from beta as Claude Data. It can use data from a Claude Sheet or a connected source such as Redshift, Snowflake, or Salesforce. You can present the data as a live dashboard, a narrative, or a story that reveals charts as the reader scrolls.

Practical distinction. Sheets is where you organize or calculate the underlying tabular data. Claude Data is where you publish a view that can refresh when its source updates. Generally available on paid plans.

8. Meetings

Claude can join Google Meet as a visible participant, take notes, capture action items, and start working on artifacts during the conversation. Chase points to dashboards, sheets, and whiteboards as examples. Connect Google Calendar and go to Settings → Capabilities → Meetings. Auto-join is optional.

Availability. Team and Enterprise beta. Google Meet is the supported meeting platform in the video and Anthropic’s launch announcement.

9. Fable Advisor

A compatible working model, such as Opus, Sonnet, or Haiku, continues executing the task and using tools. At key decision points, it can ask Fable 5.2 to review the conversation and advise it. The advisor returns guidance and the working model applies it. Use /advisor to pick an advisor in Claude Code.

Cost. Most routine work can stay on the working model, while advisor calls add their own usage. Some plans bill Fable consultations to usage credits and require one-time consent.

10. Monthly Recap

Reflect summarizes how you’ve been using Claude, including recurring topics and usage patterns. With memory on, open Settings → Wellbeing → Reflect → View.

Scope. The recap can draw on recent chats and eligible cloud Claude Code sessions and Cowork tasks. Local-only sessions are excluded. Available on Free, Pro, Max, and Ultra.
