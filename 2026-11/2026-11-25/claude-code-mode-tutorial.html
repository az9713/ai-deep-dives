How the tool loop changes

In a regular Claude Code session, Claude calls tools such as Read or Bash directly and uses their results to decide what to do next. In Code Mode, it can generate JavaScript that runs several related calls in one step. The code can run independent calls in parallel, use an earlier result in a later call, and decide what to return to Claude. The context window is the information available to the model while it works, including tool output.

Christian illustrates the difference with 40 invoices. In his example, the program checks every invoice and returns the six unpaid ones and their combined total. The work still happens. The savings come from how much detail the program passes back for the model to read.

Filter before returning results

The idea predates Claude Code’s feature. Cloudflare described a code-based way to use MCP (Model Context Protocol, a standard for connecting assistants to tools and data) in September 2025. Anthropic’s November 2025 article used a 10,000-row spreadsheet to illustrate filtering inside the execution environment. Claude Code v2.1.323 added its opt-in feature on November 12, 2026. Christian points to the later public announcement on November 17.

Pick a task with repeated tool calls

Anthropic identifies three good fits. Christian translates them into examples you can recognize from real work.

  • Repeat a change across files. Update the same price across proposal templates. Review the list of files and the diff when the changes are done.
  • Filter a large result before Claude reads it. Find receipts over $500, or extract only the campaign metrics a client asked for.
  • Run independent work in parallel. Scan 30 video scripts for mentions of pricing and return the matching passages with their source locations.

Four limitations Christian flags

  1. Use an interactive terminal. On Windows you can start the CLI in PowerShell or Git Bash, including inside VS Code’s integrated terminal. Claude’s VS Code extension panel, Desktop app, and hosted Claude Code sessions are outside the supported surfaces. Anthropic lists certain cloud model providers as eligible from v2.1.331 when the CLI itself is running in a supported terminal.
  2. The feature is experimental. It starts off by default and Anthropic may change or remove it.
  3. Session history is tied to the mode. To resume a Code Mode session, enable Code Mode again. Start a separate session to work in the default mode.
  4. Chrome and computer use are unavailable in that session. Anthropic also lists Remote Control among the unavailable integrations.

Code Mode and auto mode control different things. Code Mode changes how Claude issues tool calls. Auto mode changes permission review. Anthropic says the auto-mode classifier reviews the generated batch and that eligible background code can run for up to two hours. Code that Claude waits on has a ten-minute limit.

Turn on Code Mode

  1. Check your version with claude --version. The feature starts at v2.1.323 for Claude subscriptions and Console accounts. Anthropic requires the native build and, on Windows, Git for Windows. Run claude update if your version is older than the requirement for your setup. The documentation currently lists Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.2.
  2. Launch from the shell you use. For PowerShell, the variable stays set in that shell until you remove it or close the shell.

Windows PowerShell

$env:CLAUDE_CODE_EXPERIMENTAL_CODE_MODE = "1"
claude

Git Bash, WSL, macOS, Linux

CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 claude
  1. On first launch, choose Yes, turn on Code Mode. After Claude Code restarts, look for the banner confirming it is on. If the banner says it is unavailable, /status shows the reason.
  2. Give Claude a task that needs several tool calls. Press Ctrl+O to open the transcript viewer, then expand a Code row to see the JavaScript. Press the shortcut again to return.
Enable it by default or start a regular session

For a default opt-in, merge the environment variable below into the existing env object in ~/.claude/settings.json and start a new session. Project settings cannot turn it on.

{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_CODE_MODE": "1"
  }
}

For a fresh regular session, set the variable to 0 before running claude. Anthropic says a zero in the shell or a relevant settings file takes precedence over a one. In Git Bash, prefix the launch command with CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=0. In PowerShell, assign "0" on the first line above.

Run Christian’s invoice example as an A/B test

This exercise recreates Christian’s analogy with synthetic invoices and a known answer. Run it in two fresh sessions using the same directory, model, effort level, and permissions. Use a regular launch with the variable set to 0 for A and Code Mode with it set to 1 for B. Start A and B separately.

Generate 40 synthetic invoice files

Save this as make_invoices.py in a working folder and run python make_invoices.py or python3 make_invoices.py. Run Claude Code from that same working folder. The script creates a new sample-invoices subdirectory.

from pathlib import Path

output = Path("sample-invoices")
output.mkdir()

for i in range(1, 41):
    invoice_id = f"INV-{i:03d}"
    status = "unpaid" if i % 6 == 5 else "paid"
    cents = 1250 * i + 99
    (output / f"{invoice_id}.csv").write_text(
        f"invoice_id,status,amount_cents\n{invoice_id},{status},{cents}\n",
        encoding="utf-8",
    )

Use this prompt in both sessions

Inspect every CSV in sample-invoices/. Return the total number of invoice files checked, the IDs and amounts of all unpaid invoices, and their combined amount in cents and dollars. Report any unreadable or malformed files separately. Leave the files as they are.

Check the result first. There are 40 files, six unpaid invoices (INV-005, INV-011, INV-017, INV-023, INV-029, INV-035), and a total of 150,594 cents ($1,505.94). Zero files are malformed.

Then compare. Record time to a correct final answer, retries, and input tokens if your usage reports expose them. In the Code Mode transcript, check whether the program actually filtered the intermediate results. The regular session may independently use Bash to do the same aggregation. If it does, your comparison will capture where the dedicated mode adds value beyond a shell command. Repeat with reversed run order if you want to account for warm caches and first-run effects.

What’s next

Christian connects Code Mode to a broader hypothesis about agent design. Capable models may need fewer individually specified actions when they can compose the available tools in code. Try the invoice exercise again with 400 files and the same six matches. In a fresh folder, change the generator to range(1, 401) and replace i % 6 == 5 with i in (5, 11, 17, 23, 29, 35). Does elapsed time grow while the model-facing result stays almost flat? The experiment separates work done by the runtime from information the model needs to see.
